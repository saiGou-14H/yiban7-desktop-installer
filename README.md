# Yiban Desktop 用户版

这是 Yiban Desktop 的用户安装包发布仓库，仅提供桌面端安装文件和用户功能说明，不包含服务端源码、接口实现、部署配置或运维资料。

## 下载安装

- Windows 安装包：`download/Yiban Desktop_0.1.16_x64_zh-CN.msi`
- 当前版本：`0.1.16`
- 文件校验：`SHA256 85DDBC8EE3459479CCF0B8F52F457500CABDA82BC412157C28F7B4003D0A2B6F`

安装方式：

1. 下载 `Yiban Desktop_0.1.16_x64_zh-CN.msi`。
2. 双击安装包并按提示完成安装。
3. 启动桌面客户端后，使用分配的代理商账号登录。

## 用户可用功能

- 代理商登录、注册、邮箱验证码验证、找回密码。
- 绑定邮箱和换绑邮箱。
- 查看和管理自己名下的易班账号。
- 批量录入易班账号。
- 为易班账号配置代理，支持单账号配置和批量一键配置。
- 查看账号状态、目标进度、今日日刷增量和历史总刷增量。
- 按条件筛选账号，并选择筛选结果进入任务中心。
- 使用任务中心下发可用任务。
- 可在任务下发时选择使用账号自己的代理，或在管理员启用后选择系统内置代理。
- 查看任务执行状态、任务日志和任务恢复记录。
- 对失败或待恢复任务进行重试。
- 使用卡密充值积分，并查看积分余额和积分流水。
- 查看公告中心消息，接收弹窗公告和消息公告。
- 检查客户端版本更新，并按提示升级。

## 注意事项

- 本仓库只发布安装包，不提供源代码。
- 请勿从非官方来源下载安装包。
- 如果安装包校验值不一致，请停止安装并联系管理员。
- 账号、积分、代理和任务权限以登录后的实际页面为准。
